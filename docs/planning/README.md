## How to use this space

- Label hypotheses, external findings, decisions, and our own measured results separately.
- Keep unresolved questions visible. Do not turn an attractive idea into an established fact.
- Record failed experiments and negative results alongside successes.
- Link claims about published work to primary sources and state how deeply we reviewed them.
- Add a dated decision when the direction changes, preserving the reason for the earlier choice.

For a difficult question, use a brief Confusion Compass: state exactly what is confusing, write the 1–3 questions that would reduce it, record current guesses, then check them against evidence and revise.
